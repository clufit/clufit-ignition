# CLUFIT Phase 1 Website

## Goal
Build a fast, multi-page community and editorial website that captures newsletter emails and makes CLUFIT feel like a demanding training partner.

## Build
- Create a shared responsive shell with a disappearing-on-scroll header, desktop navigation, fullscreen animated mobile menu, custom cursor, route wipe, and large footer.
- Build the home page with the full-screen training hero, functional newsletter success state, angled light manifesto section, animated values, journal previews, resource previews, dual image marquees, and contact callout.
- Build the newspaper-style Journal index with six sample stories, categories, featured story, issue/date details, and trending sidebar.
- Add dedicated Journal category URLs for Training, Nutrition, Habits & Mindset, Recovery, and Athletes.
- Build reusable article pages with progress bar, breadcrumbs, table of contents, long-form content, partner callout, inline newsletter form, FAQs, related stories, and Article/FAQ structured data.
- Build Resources with Programs, Calculators, and Guides, including a working 1RM calculator and newsletter-gated guide downloads.
- Build About as a typographic manifesto with scroll reveals and Contact with a complete enquiry form and success feedback.

## Visual System
- Use the supplied references for composition and mood without embedding them.
- Use generated black-and-white training photography throughout, with gritty contrast and restrained color-on-hover.
- Define the supplied black, gray, light gray, red, and blue palette as semantic site tokens.
- Load Oswald 700 for condensed uppercase display type and use the supplied Helvetica-style body stack.
- Use angular cuts, hard edges, outlined type, red line details, and compact editorial spacing.

## Interaction and Performance
- Use lightweight CSS and browser-native interactions for staggered text, scroll reveals, counters, parallax, card tilt, marquees, hover fills, and route wipes.
- Respect reduced-motion settings and disable the custom cursor on touch devices.
- Use optimized local generated images with explicit dimensions, responsive crops, and lazy loading below the first screen.
- Keep forms client-side for Phase 1: submissions display the requested confirmation states; persistent email storage is not included until a data service is connected.

## SEO and Validation
- Add unique titles, descriptions, Open Graph text, canonical URLs, and social card settings to every public page.
- Add Article, FAQ, and breadcrumb structured data where relevant.
- Keep robots crawlable; sitemap setup will be deferred until a public project URL exists.
- Verify core routes, newsletter flow, calculator behavior, menus, and mobile/desktop layouts in the running preview.
